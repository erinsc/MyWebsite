What even is brainfuck?

Brainfuck is a so called "esoteric programming language". It's not meant to be actually used by people to write code because its too complicated and hard to work with. But that won't stop you of course!

Let's start with the basics. The brainfuck memory is made up or 30000 cells, each one can hold an integer number between 0 and 255 (inclusive). Theres a "Pointer" which looks at one cell from the memory.

There's 8 instructions (9 in my interpreter):

  • + Increments the cell in the pointer by 1. If the cell is holding 255 it "overflows" back to 0
  • - Decrements the cell in the pointer by 1. If the cell is holding 0 it "underflows" back to 255
  • > Moves the pointer 1 cell to the right. If there's no cells on the right then you've probably messed up because you're using way too much memory
  • < Moves the pointer 1 cell to the left. If there's no cells on the left the program crashes
  • [If the cell in the pointer is notholding a 0, goes inside a loop
  • ] If the cell in the pointer is holding a 0, exit the loop, otherwise repeat it
  • . Print the cell in the pointer as an ASCII value
  • . Reads a character from the user and saves its value into the cell in the pointer. If there's no more characters the program pauses
  • ! Pauses the program (This one isn't in the original brainfuck specification)
